# Machine Learning Regression Projects

This repository contains my hands-on Machine Learning projects focused on **Regression** using **Python and Scikit-learn**.

The projects helped me understand regression concepts through practical datasets, including **Exploratory Data Analysis (EDA), model building, and prediction**.

## Projects

### 1. Single Linear Regression — House Price Prediction

A Single Linear Regression model built to understand the relationship between **property area and price**.

Before building the model, I performed **Exploratory Data Analysis (EDA)** to understand the dataset and the relationship between the input feature and target variable.

**Objective:**

* Analyze the dataset using EDA.
* Use property area as an input feature.
* Train a Single Linear Regression model.
* Predict the estimated price based on the given area.

**Concepts Covered:**

* Exploratory Data Analysis (EDA)
* Linear Regression
* Feature and target selection
* Model training
* Prediction using Scikit-learn

**Dataset:**
`single_linear_regression_house_prices.csv`

---

### 2. Multiple Linear Regression — Startup Profit Prediction

A Multiple Linear Regression model built using the **50 Startups dataset** to understand how multiple business-related features can be used to predict startup profit.

Before model building, I performed **Exploratory Data Analysis (EDA)** to understand the dataset and relationships between the features and target variable.

**Objective:**

* Analyze the startup dataset using EDA.
* Work with multiple input features.
* Train a Multiple Linear Regression model.
* Predict startup profit using the available features.

**Concepts Covered:**

* Exploratory Data Analysis (EDA)
* Multiple Linear Regression
* Multiple features
* Model training
* Prediction using Scikit-learn

**Dataset:**
`50_Startups_dataset.csv`

---

### 3. Polynomial Regression — Level and Salary Prediction

A Polynomial Regression model built using a **Level–Salary dataset** to understand how a non-linear relationship can be modeled.

The project helped me understand why a simple Linear Regression model may not always represent a non-linear relationship effectively and how Polynomial Regression can provide a more flexible fit.

**Objective:**

* Study the relationship between job level and salary.
* Understand the limitations of fitting a simple linear relationship to non-linear data.
* Build a Polynomial Regression model.
* Use polynomial features to model the non-linear relationship.

**Concepts Covered:**

* Non-linear relationships
* Polynomial Regression
* Polynomial features
* Model fitting
* Prediction using Scikit-learn

**Dataset:**
Level–Salary dataset
